# Glass Notebook

A glass-styled note-taking app for Windows, with drawing boards, themes, and sync with the phone app.

## Install

1. Open **[Releases](https://github.com/zw7z/Glass-Notebook-Releases/releases/latest)** and download `Glass_Notebook_Setup.exe`.
2. Run it. Windows may show **"Windows protected your PC"**, because the installer isn't signed yet. Click **More info → Run anyway**.
3. It installs for your user only, so it needs no admin permission.

## Updates

The app updates itself: **Settings › About › Check for Updates**, and it also checks quietly once a day. Updating never touches your notes, which are kept in `Documents\Glass Notebook`.
